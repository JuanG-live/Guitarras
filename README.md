# 🎸 GuitarLA - Guitar E-commerce

Online guitar store developed with React and Vite.

## 🚀 Live Demo

[View live project](https://stupendous-dusk-468a98.netlify.app/)

## 📋 Features

- Guitar catalog with detailed information
- Functional shopping cart
- Quantity management (add/decrease)
- Maximum limit of 5 units per product
- Data persistence with LocalStorage
- Automatic total calculation
- Responsive design

## 🛠️ Technologies

- React
- JavaScript
- Vite
- CSS

## 💻 Installation
```bash
# Clone repository
git clone [your-repo]

# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for production
npm run build
```
